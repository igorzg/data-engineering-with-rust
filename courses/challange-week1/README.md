# Challenge Week 1

## Usage

```text
cargo run -- all                  # run all five tasks on the bundled sample data
cargo run -- csv [file] [column]  # defaults: data/sales.csv revenue
cargo run -- words [file]         # default: data/sample.txt
cargo run -- top10 [file]         # default: data/sample.txt
cargo run -- connected            # demo of a connected and a disconnected graph
cargo run -- kosaraju             # demo strongly connected components
```

Run the test suite with:

```text
cargo test
```
